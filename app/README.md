# skills-browser reconstruído

Interface desktop local para consultar o ranking público do skills.sh e instalar/remover skills no escopo global.

## Requisitos

- Windows
- Python 3
- Node.js/npx

## Executar

```bat
launch.bat
```

A interface abre em `http://127.0.0.1:8765/`.

## Arquivos

- `index.html`: interface recuperada do aplicativo original
- `styles.css`: estilos recuperados
- `app.js`: comportamento da interface recuperado
- `server.py`: servidor local e integração com skills.sh/npx
